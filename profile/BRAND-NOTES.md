# Hidden Tokens — GitHub profile assets

These files are intended for the public GitHub organization profile repository:

```text
hidden-tokens/.github/
└── profile/
    ├── README.md
    └── banner.svg
```

## Brand implementation

Colors from the Hidden Tokens brand kit:

- Ground: `#0B0D12`
- Surface: `#14161F`
- Line: `#242838`
- Foreground: `#EDEBF3`
- Muted: `#8B87A3`
- Violet: `#7C5CFF`

The banner uses the brand kit's geometric mark: two vertical rounded bars crossed by a horizontal violet bar. Typography is a system monospace stack, matching the kit's code-oriented visual language.

## Publish

1. Create or open `https://github.com/hidden-tokens/.github`.
2. Add `profile/README.md` and `profile/banner.svg`.
3. Commit to the `main` branch.
4. Confirm the banner is visible at:
   `https://raw.githubusercontent.com/hidden-tokens/.github/main/profile/banner.svg`

The README links to the product's existing public destinations. Verify those destinations and the WhatsApp contact before publishing.

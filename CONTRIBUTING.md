# Contributing to Hidden Tokens

Thanks for helping make AI-assisted work safer. Every contribution — a sharp bug report, a use case we hadn't considered, a doc fix — helps.

## The one rule above all

**Never include confidential material in any public contribution.** This applies everywhere in this organization:

- No real names, identifiers, amounts, or client data in issues, pull requests, code, tests, fixtures, or screenshots.
- No token↔value mappings or restored documents.
- Test data always uses obviously fictional values (e.g. `CLIENT_A`, `INVOICE_0042`).

If you accidentally posted something sensitive, contact us immediately at [info@hiddentokens.com](mailto:info@hiddentokens.com) so we can help remove it.

## Ways to contribute

### Report bugs

Use the [bug report template](https://github.com/hidden-tokens/.github/issues/new?template=bug_report.yml) and include:

- Which surface (desktop app, browser extension, docs) and version
- Numbered steps to reproduce with a **non-sensitive** example document
- What you expected to happen

### Suggest features

Use the [feature request template](https://github.com/hidden-tokens/.github/issues/new?template=feature_request.yml). Describe the workflow you're trying to achieve — use cases drive priorities more than solution details.

### Improve documentation

The [Academy](https://hiddentokens.com/academy/) is the main learning resource. If a guide is unclear or missing a step, tell us — or open a pull request against the relevant repository.

### Contribute code

Code contributions happen in the individual product repositories, each with its own setup instructions. General expectations across all of them:

- Keep changes focused — one topic per pull request.
- Follow the PR template, especially the privacy checklist.
- Fictional test data only (see the one rule above).

## Pull requests

1. Open an issue first for anything beyond a small fix, so the approach can be agreed on.
2. Reference the issue in your PR (`Fixes #123`).
3. Keep the description honest about what was tested and what was not.
